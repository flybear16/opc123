# 各层最优秀技能列表

> 基于 opc123 项目完整调研 · 精选各层最具价值的 AI 技能
> 整理时间：2026-05-22

---

## 0. 选品原则

从 opc123 已调研的 9 个项目中，按以下维度综合评估：

| 维度 | 说明 |
|------|------|
| **方法论深度** | 是否有成熟方法论支撑（Teresa Torres、Marty Cagan 等） |
| **生产验证** | 是否在实际产品中使用（非概念项目） |
| **自动化程度** | Skill 之间是否自动推荐、全流程覆盖 |
| **社区活跃度** | Stars 数量、更新频率、贡献者数量 |
| **易用性** | 安装复杂度、学习曲线 |
| **可扩展性** | 是否开放知识库、支持自定义 |

## 10. 安装命令汇总

```bash
# ===== 模型路由 =====
# 9router（健康监控）
git clone https://github.com/Ubrewokan/9router-health-monitor.git

# ds2api（一键部署 Vercel）
# https://github.com/CJackHwang/ds2api

# ===== 需求发现 =====
# opc-skills
/plugin marketplace add ReScienceLab/opc-skills
/plugin install requesthunt@opc-skills

# ===== 战略规划 =====
# dbskill
/plugin marketplace add dontbesilent2025/dbskill
/plugin install dbs@dontbesilent-skills

# pm-skills
/plugin marketplace add phuryn/pm-skills

# ===== 产品设计 =====
# open-design
pnpm tools-dev

# open-codesign
brew install --cask opencoworkai/tap/open-codesign

# ===== 开发交付 =====
# superpowers
/plugin marketplace add obra/superpowers-marketplace
/plugin install superpowers@superpowers-marketplace

# gstack
git clone --single-branch --depth 1 https://github.com/garrytan/gstack.git ~/.claude/skills/gstack

# opchain
# https://opchain.dev

# ===== 增长运营 =====
# seo-geo（包含在 opc-skills 中）
/plugin install seo-geo@opc-skills

# ===== 知识记忆 =====
# gbrain
bun install -g github:garrytan/gbrain
gbrain init --pglite
```
