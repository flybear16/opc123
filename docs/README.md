# 🛠️ opc123 - AI 开源工具 & Agent Skills 调研

> 专注调研 AI 开源设计工具和对标 Claude Design 的优秀替代品

---

## 🎯 项目定位

opc123 是一个专注于 **AI 开源设计工具**和 **Agent Skills** 的研究项目，对标 Claude Design，调研市场上优秀的开源替代品。

**七层架构**：从模型路由 → 需求发现 → 战略规划 → 产品设计 → 开发交付 → 增长运营 → 知识记忆，覆盖 AI 产品开发全流程。

## 📊 快速导航

### 按场景推荐

| 场景 | 推荐工具 |
|------|---------|
| 有 Agent 工作流的开发者 | open-design |
| 不想装 CLI 的普通用户 | open-codesign |
| 创始人/CEO 高效工作 | gstack |
| 个人知识管理 | gbrain |
| 独立产品调研到设计 | opc-skills |
| 跨会话开发全流程 | opchain |
| 商业诊断与执行力 | dbskill |
| 系统化产品发现流程 | pm-skills |
| 双模型对抗验证 | oh-my-claudecode |

### 三套精选装备

**独立开发者装备**
```
需求发现 → opc-skills/requesthunt
商业诊断 → dbskill/diagnosis + goal
原型设计 → open-codesign + logo-creator
代码交付 → gstack + superpowers
知识记忆 → gbrain
```

**PM/产品经理装备**
```
需求发现 → pm-skills/brainstorm + interview-script
PRD撰写 → pm-skills/write-prd
原型设计 → open-design
代码交付 → superpowers + opchain
增长运营 → pm-skills/metrics-dashboard
```

**创始人/CEO装备**
```
模型路由 → ds2api（协议转换）
需求发现 → dbskill/discover + opc-skills/requesthunt
战略规划 → dbskill/diagnosis + benchmark + goal
产品设计 → open-design + gstack/plan-ceo-review
代码交付 → gstack（全套 23 工具）
增长运营 → dbskill/content + seo-geo
知识记忆 → gbrain
```

## 🛠️ 安装命令速查

```bash
# === 设计工具 ===
# open-design
pnpm tools-dev

# open-codesign
brew install --cask opencoworkai/tap/open-codesign

# === Skills ===
# opc-skills
/plugin marketplace add ReScienceLab/opc-skills

# dbskill
/plugin marketplace add dontbesilent2025/dbskill

# pm-skills
/plugin marketplace add phuryn/pm-skills

# === 工作流 ===
# gstack
git clone --single-branch --depth 1 https://github.com/garrytan/gstack.git ~/.claude/skills/gstack

# superpowers
/plugin marketplace add obra/superpowers-marketplace
/plugin install superpowers@superpowers-marketplace

# === 记忆 ===
# gbrain
bun install -g github:garrytan/gbrain
gbrain init --pglite
```
