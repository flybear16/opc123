## 2. 核心 Skill 详解

### 2.1 论文X光机

**一句话**：把学术论文拆解成可行动的"餐巾纸公式"——写在餐巾纸背面的商业洞见。

**核心流程**：
- 读论文 → 提炼核心观点
- 问"这个道理能迁移到哪些场景"
- 写成 3 句话的餐巾纸笔记

### 2.2 深度拆书机

**一句话**：三轮认知压缩——从一本书到一张卡片。

| 轮次 | 输入 | 输出 |
|------|------|------|
| 第一轮 | 全书 | 核心论点 |
| 第二轮 | 核心论点 | 可执行行动 |
| 第三轮 | 行动 | 一张 HTML 记忆卡 |

### 2.3 结构化圆桌讨论

**一句话**：多人物辩证对话，模拟苏格拉底式追问。

- 设置多个角色（支持者、质疑者、专家）
- 围绕一个观点展开多轮辩论
- 最终输出求真结论
